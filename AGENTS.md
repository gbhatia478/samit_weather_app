# Project Instructions

- Treat iPhone-sized screens as a required target for every UI change.
- Before deploying any UI change, check the layout at approximately 390px wide and 844px tall, including Safari safe-area padding.
- Make sure the primary content and controls are usable without horizontal clipping.
- The primary action must remain visible and unclipped above the iPhone safe-area inset, even when the page content is taller than one screen.
- Keep the page vertically scrollable when secondary content cannot reasonably fit on one screen.
